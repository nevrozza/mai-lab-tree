# ЛР1. Вариант 8 (Без рекурсии)
### Определить число вершин дерева, степень которых совпадает со значением элемента

В проекте реализована программа для построения и обработки дерева общего вида. По варианту нужно посчитать количество вершин, у которых степень совпадает со значением, записанным в самой вершине.

Отдельное условие этой реализации - обход выполняется без рекурсии. Для этого используется стек.

## Код

- [**main.c**](./main.c) - цикл CLI
- **tree** - реализация дерева и утилит для работы с ним
- **cli** - более user-friendly функции, которые пишут, что пошло не так
- **stack** - стек для обхода дерева без рекурсии
- **utils** - ошибки, которые крашат (`memoryError`)

> [!NOTE]
> В этой лабораторной рекурсию пришлось заменить явным стеком. По сути, программа сама хранит вершины, к которым еще нужно вернуться во время обхода дерева.

# Отчёт по лабораторной работе №1 по курсу "Фундаментальная информатика"

**Тема:** Обработка деревьев.

**Цель:** Научиться работать с деревьями общего вида и реализовать обработку дерева без рекурсии.

**Задание:** Составить программу для построения и обработки дерева общего вида, поддерживающую режим CLI. Написать алгоритм, позволяющий подсчитать количество вершин дерева, степень которых совпадает со значением элемента.

> **Вариант 8:** Определить число вершин дерева, степень которых совпадает со значением элемента.

## Идея и метод решения

Дерево общего вида отличается от бинарного дерева тем, что у вершины может быть произвольное количество потомков. Поэтому степень вершины здесь удобно понимать как количество ее непосредственных детей.

Для каждой вершины нужно сравнить:

```text
значение вершины == количество ее потомков
```

Если условие выполняется, вершина учитывается в ответе.

Так как обход должен быть без рекурсии, вместо рекурсивного вызова используется стек. В стек помещаются вершины, которые еще нужно обработать. Пока стек не пустой, из него извлекается очередная вершина, для нее считается количество потомков, после чего ее дети добавляются в стек.

> [!IMPORTANT]
> Здесь важно считать именно непосредственных потомков вершины, а не все вершины в ее поддереве. Например, если у вершины два ребенка, а у каждого из них еще есть свои дети, степень этой вершины все равно равна `2`.

## Структура программы

Проект логически разделен на несколько частей:

- `main.c` отвечает за запуск программы и CLI-цикл
- модуль `tree` хранит структуру дерева и операции над ним
- модуль `stack` используется для нерекурсивного обхода
- модуль `cli` отвечает за ввод команд и человекочитаемые сообщения
- модуль `utils` содержит общие ошибки и вспомогательные функции

Такой вариант разделения удобен для отладки: работа с деревом не смешивается с вводом команд, а обход дерева не зависит от конкретного формата CLI.

## Алгоритм подсчета

1. Проверить, что дерево не пустое
2. Создать стек для обхода
3. Положить корень дерева в стек
4. Пока стек не пустой, извлекать очередную вершину
5. Для текущей вершины посчитать количество ее непосредственных потомков
6. Сравнить это количество со значением вершины
7. Если значения совпадают, увеличить счетчик
8. Добавить потомков текущей вершины в стек
9. После обхода вывести итоговый счетчик

## Тонкости реализации

В этой работе самая важная часть связана с тем, как обойти дерево общего вида без рекурсии и при этом не потерять ни одну вершину.

При реализации нужно учитывать:

- дерево может быть пустым
- у вершины может не быть потомков
- у вершины может быть несколько потомков
- степень вершины считается только по непосредственным детям
- обход не должен зависеть от глубины дерева
- стек нужно корректно очищать после работы
- при ошибке выделения памяти программа должна завершиться контролируемо

Без рекурсии код становится чуть более явным: вместо того чтобы полагаться на системный стек вызовов, программа сама управляет стеком вершин. Это хорошо показывает, что рекурсивный обход дерева можно заменить обычным циклом.

Кратко про обработку ошибок: CLI должен обрабатывать некорректные команды, неправильные аргументы, попытку обработать пустое дерево и ошибки выделения памяти. В таких случаях программа выводит понятное сообщение или завершает работу через `memoryError`, если продолжать уже нельзя.

> [!NOTE]
> Отдельно полезно тестировать дерево, где значение вершины совпадает со степенью случайно, например `0` у листа. Лист имеет степень `0`, поэтому такие вершины тоже подходят под условие.

Примеры тестов:

| **Сценарий** | **Что проверяется** |
|:------------|:--------------------|
| пустое дерево | корректная обработка отсутствия корня |

## Сложность

Каждая вершина дерева обрабатывается один раз. Если в дереве `n` вершин, то обход работает за `O(n)`.

| **Операция** | **Сложность** |
|:------------|:--------------|
| обход дерева | `O(n)` |
| подсчет степени одной вершины | зависит от количества ее детей |
| итоговый подсчет по всему дереву | `O(n)` |
| дополнительная память под стек | `O(h)` в глубину обхода, в худшем случае `O(n)` |
